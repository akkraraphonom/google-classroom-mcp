# Google Classroom MCP

เซิร์ฟเวอร์ MCP แบบอ่านอย่างเดียวสำหรับบัญชีนักเรียน รันด้วย Node.js 22 ขึ้นไปผ่าน stdio ในเครื่อง

## เปิดใช้งานครั้งแรก

### สำหรับ AI ที่ติดตั้งให้ผู้ใช้

เมื่อผู้ใช้ขอให้ติดตั้ง MCP นี้ ให้ AI จัดการตั้งค่าและทดสอบตั้งแต่ต้นจนจบ ผู้ใช้รอจน AI เปิดหน้าของ Google ให้ จากนั้นทำเฉพาะขั้นตอนที่ Google ต้องให้เจ้าของบัญชีทำเอง เช่น เลือกบัญชี ล็อกอิน ยืนยันตัวตน และกดอนุญาตหรือยอมรับเงื่อนไข แล้วให้ AI ทำต่อโดยอัตโนมัติ

1. ตรวจ Node.js, ติดตั้งด้วย `npm ci` และตรวจ `codex mcp get google-classroom` ก่อนลงทะเบียนซ้ำ จากนั้นลองเรียก `list_courses` โดยใช้ `pageSize: 1` เพื่อตรวจว่ามีบัญชีเชื่อมอยู่แล้วหรือยัง
2. ถ้ายังไม่มีบัญชีเชื่อม ให้ตรวจไฟล์ Desktop OAuth ที่มีอยู่ในเครื่องก่อน ถ้ายังไม่มี ให้เปิด Google Cloud Console และทำขั้นตอนสร้างโปรเจกต์ เปิด Classroom API กับ Drive API ตั้งค่า Google Auth Platform และสร้าง Desktop client ให้ผู้ใช้ เมื่อใช้บัญชีในองค์กรเดียวกับโปรเจกต์และ Google มีตัวเลือก Internal ให้เลือก Internal ถ้าตั้งเป็น External / Testing ให้เพิ่มบัญชี Classroom ที่ผู้ใช้เลือกใน Test users
3. ดาวน์โหลด OAuth JSON ลงเครื่องและหาพาธเอง เก็บไว้นอกโฟลเดอร์โปรเจกต์โดยไม่แสดงค่าในไฟล์ การติดตั้งใหม่ให้ใช้ client ที่ตั้งค่าสำหรับบัญชีหรือองค์กรนั้น เก็บ OAuth JSON และโทเคนแยกจากไฟล์แจกจ่าย จากนั้นรัน `node login.mjs "<พาธไฟล์ JSON>"` และเปิด URL ที่คำสั่งแสดงในเบราว์เซอร์ ให้ผู้ใช้ทำขั้นตอน Google แล้วรอจน PowerShell รายงานว่าบันทึกการอนุญาตสำเร็จ
4. หลังเชื่อมบัญชี ให้เรียก Classroom จริงด้วย MCP และไล่ `nextPageToken` ทั้งรายวิชาและงานจนหมดทุกหน้า ตรวจสถานะงานของผู้ใช้ แล้วหาไฟล์แนบ PDF และ Word หรือ Google Docs จากงานที่เข้าถึงได้ ดาวน์โหลดตัวอย่างและเปิดอ่านเนื้อหาจริง รายงานจำนวนที่ดึงได้และไฟล์ที่อ่านได้ หากไม่มีไฟล์ประเภทนั้นหรือมีปัญหาสิทธิ์ ให้บอกผลตามที่พบ
5. ถ้าติดหน้าล็อกอิน ข้อกำหนดของ Google นโยบายองค์กร หรือข้อจำกัดเครื่องมือ ให้ระบุจุดที่ติดและขอให้ผู้ใช้ช่วยเฉพาะขั้นตอนนั้น จากนั้นทำงานต่อเมื่อผ่านแล้ว

### ขั้นตอนอ้างอิงสำหรับตั้งค่าด้วยมือ

1. ใน [Google Cloud Console](https://console.cloud.google.com/) สร้างหรือเลือกโปรเจกต์ เปิดใช้ **Google Classroom API** และ **Google Drive API** ในโปรเจกต์เดียวกัน
2. ตั้งค่า **Google Auth Platform** (Branding และ Audience) ถ้าเลือก External และอยู่ในโหมด Testing ให้เพิ่มอีเมลที่ใช้ Classroom ใน **Test users** บัญชีโรงเรียนอาจต้องให้แอดมินอนุญาตแอปก่อน
3. ใน **Clients** สร้าง OAuth client ประเภท **Desktop app** แล้วดาวน์โหลดไฟล์ JSON เก็บไว้ในเครื่อง
4. เปิด PowerShell ในโฟลเดอร์นี้ แล้วรันคำสั่งด้านล่าง โดยเปลี่ยนพาธให้ตรงกับไฟล์ที่ดาวน์โหลด

   ```powershell
   npm ci
   node login.mjs "C:\path\to\client_secret.json"
   ```

5. เปิด URL ที่คำสั่งแสดง เลือกบัญชี Classroom และให้สิทธิ์อ่าน รอจน PowerShell แสดงข้อความว่าเก็บการอนุญาตแล้ว ถ้าตั้งค่า External/Testing โดยปกติต้องล็อกอินใหม่เมื่อครบ 7 วัน
6. ถ้าเครื่องนี้ยังไม่ได้ลงทะเบียน MCP ให้รันคำสั่งด้านล่างจากโฟลเดอร์นี้ จากนั้นเปิด Codex ใหม่

   ```powershell
   codex mcp add google-classroom -- node (Join-Path (Get-Location).Path 'index.mjs')
   ```

ลองพิมพ์ใน Codex ว่า “ดูงาน Classroom ที่ยังไม่ได้ส่งทุกวิชา แล้วเปิดไฟล์แนบของงานที่ใกล้ครบกำหนดที่สุด”

## ขอบเขต

- อ่านรายวิชา โจทย์ กำหนดส่ง สถานะการส่งของตัวเอง ประกาศ และสื่อการเรียน แต่ละรายการรองรับการดึงหน้าถัดไป
- อ่านข้อมูลไฟล์แนบและดาวน์โหลดไฟล์ Drive ที่บัญชีเปิดและดาวน์โหลดได้ ไฟล์ปกติ เช่น PDF รูป และ Word เก็บในโฟลเดอร์ชั่วคราวของ Windows
- Google Docs ส่งออกเป็นข้อความ, Sheets เป็น XLSX และ Slides/Drawings เป็น PDF สิทธิ์อ่าน Drive ครอบคลุมไฟล์อื่นที่บัญชีเข้าถึงได้ด้วย ตัวเซิร์ฟเวอร์อ่านตาม ID ที่ร้องขอ
- Google Forms, YouTube และเว็บภายนอกเปิดจากลิงก์ตามสิทธิ์ของบัญชี ไฟล์ Drive จำกัด 100 MiB ต่อไฟล์ ส่วนการส่งออกไฟล์ Google Workspace อยู่ภายใต้เพดานของ Google ที่ 10 MB
- โทเคนและค่า client อยู่ใน `%LOCALAPPDATA%\GoogleClassroomMcp\session.json` เก็บไฟล์นี้และ OAuth client JSON ไว้ส่วนตัว การถอนสิทธิ์ทำได้จาก [Google Account Connections](https://myaccount.google.com/connections)
